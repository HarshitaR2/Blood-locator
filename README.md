# Blood Locator

A simple, responsive web app that connects users who need blood with nearby donors and blood banks. Blood Locator is built with HTML, CSS, and JavaScript, and includes features for finding resources, contacting help, and learning about safe donation practices.

## 🌟 Key Features

- Responsive landing page with clear call-to-action sections.
- Intuitive UI for locating blood banks and donors nearby.
- Donation eligibility information for first-time and repeat donors.
- Contact form for requests and urgent needs.
- Lightweight frontend-only implementation for easy deployment.

## 📁 Project Structure

- `index.html`: Main website page and navigation.
- `style.css`: Visual styling, layout, and responsive media queries.
- `script.js`: Interactive behaviors and front-end logic.
- `images/`: Icons, banners, and graphics used in the website.

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/HarshitaR2/Blood-locator.git
   cd Blood-locator
   ```
2. Open `index.html` in your browser:
   - Double-click the file, or
   - Use a local server (recommended):
     ```bash
     python3 -m http.server 8000
     ```
     Then visit `http://localhost:8000/`.

## 🛠️ Development

- Edit `index.html` to adjust content, sections, and links.
- Edit `style.css` to change colors, spacing, fonts, and layout.
- Edit `script.js` to add interactivity (form validation, search filters, UI effects).
